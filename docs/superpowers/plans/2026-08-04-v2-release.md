# v2.0.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать релиз v2.0.0 по спеке `docs/superpowers/specs/2026-08-04-v2-release-design.md`: 8 критических фиксов, оживление лояльности/рефералов, 8 новых фич, E2E.

**Architecture:** Три волны. Волна 1 — платёжный пайплайн, инфраструктура, схема БД и контракты (4 параллельных задачи с непересекающимися файлами). Волна 2 — 9 параллельных фич поверх контрактов волны 1. Волна 3 — E2E, документация, релиз.

**Tech Stack:** Go 1.24 (no CGO, modernc.org/sqlite), tgbotapi v5 + raw MakeRequest для новых Bot API полей, Redis (опционально), vanilla JS Mini App (embed).

## Global Constraints

- Модуль `shop_bot`, Go `1.24.0`; новые внешние зависимости запрещены (стандартная библиотека + уже имеющиеся).
- Все пользовательские строки — через i18n (`b.t(lang, key)` / `i18n.Tf`), ключи добавляются во все 5 локалей: `ru` (эталон), `en`, `es`, `de`, `zh`.
- Все контексты: `ctx` первым аргументом; в хендлерах — `b.handlerCtx()`; в HTTP — `r.Context()`.
- Параллельность — по скиллу go-concurrency: `wg.Add` до `go`, `defer wg.Done()`, блокирующие операции отменяемы, у каждой горутины владелец.
- Ошибки не глотать: `_ =` только с комментарием-обоснованием.
- Тесты: `go test ./<пакет>/` таргетно в задаче; полный `./...` и `-race` — только в волне 3.
- Git: субагенты НЕ выполняют git-команды; коммитит координатор после верификации волны.
- Новые callback-префиксы фиксированы: `review:`, `sub:`, `ref:` — коллизии запрещены.
- Миграции: файлы `internal/storage/migrations/NNN_name.sql`, номера закреплены за задачами (012–015), формат как в 008–011.
